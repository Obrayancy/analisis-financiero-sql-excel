# analisis-financiero-sql-excel
En este nuevo caso se trabajo con datos po rmes de ingresos, gastos, costos para calcular variaciones en utilidad y analizar el margen de rentabilidad

Objetivo
Evaluar el desempeño financiero de una empresa mediante el análisis de ingresos, costos, gastos y rentabilidad.
Herramientas utilizadas
- SQL Server
- Excel

Análisis realizado
- Cálculo de utilidad por mes
- Margen de rentabilidad (%)
- Comparación entre meses

Resultados clave
- Mayor utilidad: Abril (S/5000)
- Mayor margen: marzo (~44%)
- Diferencia entre volumen y eficiencia

Insights
- El mes con mayor utilidad no tiene el mejor margen
- Existe variación en la eficiencia operativa
- Oportunidad de optimizar costos

Conclusión
Se recomienda analizar la estructura de costos en meses de alto ingreso y replicar estratégias de meses con mayor margen
